# Sistema grafico FluenteMente

## Identità
- Brand: **FluenteMente** (sempre tutto attaccato).
- Palette principale esistente: arancione `#ff8000`, blu navy `#1a202c` / grigio-blu `#2d3748`, sfondo `#f8fafc`, bianco.
- Font: stack di sistema sans-serif per velocità e coerenza cross-platform.
- Forme: card con bordi arrotondati, ombre leggere, CTA arrotondate, ampio spazio verticale.

## File grafici
- `assets/css/main.css`: foglio di stile principale e breakpoint responsive originali.
- `assets/css/components/`: fogli di stile dei componenti riutilizzabili.
- `assets/img/og-default.jpg`: immagine social/Open Graph del brand.
- `_includes/`: elementi condivisi e componenti UI generici.
- `_layouts/`: impalcatura comune per home, pagine e futuri articoli.
