# Archivio delle versioni editoriali precedenti

Questa cartella conserva integralmente il contenuto che si trovava in `articoli/` prima del consolidamento del 25 ottobre 2026.

- `articoli-pre-consolidamento/` contiene le vecchie versioni e i file accessori/orfani presenti nella cartella attiva prima dell'intervento.
- Le versioni editoriali più recenti e canoniche dei 30 PIN sono ora in `articoli/`.
- I file in `_archive/` sono conservati per recupero e confronto, non sono sorgenti pubbliche e non devono essere ripristinati nella build senza una revisione esplicita.

I permalink degli articoli attivi sono stati mantenuti invariati: lo spostamento riguarda il percorso del file sorgente, non l'URL pubblico.
