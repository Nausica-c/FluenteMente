# FluenteMente

Sito Jekyll di mini-lezioni di inglese per un pubblico italiano.

- Sito: https://nausica-c.github.io/FluenteMente/
- Sorgenti articoli: `articoli/` (PIN01–PIN30)
- Hub SEO: `percorsi/`
- Componenti: `_includes/` e `_layouts/`
- Asset: `assets/`
- Pagine di servizio: `pages/servizi/`
- Documentazione: `docs/`
- Versioni storiche e duplicati conservati: `_archive/` (escluso dalla build)

Prima del deploy, eseguire la build Jekyll su GitHub Actions e verificare le istruzioni in `docs/pinterest-lo-sapevi-che/controlli_pre-pubblicazione.md`.
